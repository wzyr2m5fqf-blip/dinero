# dinero

Negocio: **webs y automatizaciones para negocios locales sin presencia online.**

La idea: haces una web de demo de un negocio real *antes* de contactarle, se la enseñas y le ofreces dejársela funcionando.

## Contenido

- `plantilla/`: web lista para adaptar. Solo hay que editar `plantilla/config.js` (nombre, servicios, horario, reseñas, WhatsApp...). Abre `plantilla/index.html` en el navegador para verla.
- `ventas/encontrar-clientes.md`: cómo encontrar negocios en Google Maps y organizarte.
- `ventas/guion-y-precios.md`: qué decir, cuánto cobrar y cómo responder a las objeciones.

## Flujo por cliente

1. Encuentra un negocio sin web en Google Maps.
2. Copia `plantilla/` a `demos/<nombre-negocio>/` y rellena `config.js` con sus datos.
3. Publica la demo para tener un enlace.
4. Enséñasela en persona o por WhatsApp.
5. Cobra el 50 %, conecta el dominio y cobra el resto. Después, mantenimiento mensual.
